# Security

This early demo is intended for execution on a trusted development workstation on localhost only. No authentication, transport security or industrial safety interlocks are implemented.

**Do not expose the HTTP server to the public internet or connect it to real industrial equipment.** Do not use this prototype to drive actuators or make safety-critical operational decisions.

For security reports, open a GitHub security advisory once repository security reporting is enabled. Avoid publishing exploit details before a fix.
